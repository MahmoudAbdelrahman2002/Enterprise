Facebook register / login

Sign in with Facebook. This page sends the access token to POST /api/v1/client/auth/external.

1) Create an app at developers.facebook.com
2) Put App ID + App Secret in ExternalAuth:Facebook
3) Replace FACEBOOK_APP_ID below with the same App ID
4) In Facebook Login settings add Valid OAuth Redirect URI: http://localhost:5207/facebook-signin.html
5) Use Cases → Facebook Login → Customize → add permission email (Ready for testing)
